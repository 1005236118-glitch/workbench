APN工作方向指南针
2026.8.31 院领导汇报反馈 · 每一项工作、每一次汇报，都对照这里校准方向

🎯 两大主线

  • 专病管理：路径标准化 · 构建全程管理路径、深耕重点环节 · 多学科联合、专科引领、特色突出
  • 急医生之所急：不仅关注护理问题，更关注医生关注的问题，做精准护理
  • 优势病种打法：选优势病种 → 形成可复制方法 → 院级 → 德阳市 → 全国推广
  • 专项管理：多维度评价 · 以病人为中心 · 多科室多部门协同，把病人留在医院

📌 关键要求

  • 让医生和护士知道 APN在做什么
  • 照护能力建设：带领科室老师制定照护标准
  • 特殊患者 医护共同查房，聚焦重点问题
  • 工作落地到患者照护实际
  • 经验总结标准化、可复制、可推广

❓ 灵魂三问（每项工作自检）

  • 问一患者得到了什么？我们得到了什么？
    → 有哪些数据可以拿出来展示？
  • 问二医生在这个过程中得到了什么？
    → 医疗认可 · 患者认可 · 护士认可，做到了吗？
  • 问三这项工作是否落地到患者的照护实际？
    → 病人是整体，别停留在纸面上
⚡ 记录每一条工作前，先用灵魂三问过一遍——能回答的工作才有价值，能展示的数据才是成果
